## What I expose
All in `/api` (`uv run uvicorn app.main:app --port 8000`); shapes in PLAN.md §10 + contract-changes.md; details in `api/README.md`.
- `POST /estimate` `{url | address, unit_sqft?}` → §10 estimate (+ session_id, questions, co2_t, badges, grade_band_usd, ...)
- `POST /answer` `{session_id, question_id, answer}` → same shape, narrower; `GET /session/{id}` → the latest body
- `GET /fixes/{session_id}` → GRH fixes ranked by CO₂ per net $, landlord email
- `GET /forecast/{session_id}` → next 7 days of heating + cooling $ vs typical, alerts (P4 reminders)
- `POST /compare` `{listings: [a, b]}` → `{a, b, winner, diff_usd_yr, confident}`
- `POST /calibrate` `{session_id, bill_image_base64}` | `{session_id, therms, kwh, start, end}` → pct (percent), streak, badges
- `GET /city` (GeoJSON, gzip) and `GET /leaderboard?scope=city|neighborhood`
- `GET /health`, `GET /debug/features?address=…` (internal); `get_features(address)`, `parse_listing_url(url)` in code

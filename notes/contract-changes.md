- **additive**, P3 (P3-01 map widget), acks: P1 [ ] P2 [ ] P3 [x] P4 [ ]
  - New `GET /map/{session_id}` → `MapWidgetData` (shape in `web/components/hidden-rent-map/types.ts` on `p3/map-widget`; example `web/mocks/map/912-mary-st.json`).
  - Contents: building footprint + LiDAR `height_ft` + stories/floor area/unit size (each with a source); ~160 m of neighbor footprints with `height_ft`; block-group polygon + ACS median year built + gas/electric heat shares; `steps[]` (public record, then one per answered question), each with P1's estimate (annual + seasons + typical error) and the look-alike cloud (`count`, sorted `usd_yr` sample ≤ 400, p10/p50/p90); `sources[]`.
  - Nothing in §10 changes; the widget just reads more.
- **additive**, P2 (integration, dev `4602d55`), acks: P1 [ ] P2 [x] P3 [ ] P4 [ ]
  - `POST /estimate` request: optional `unit_sqft` (100–10,000, otherwise 422 `bad_unit_sqft`).
  - Response: `building.address`, `building.sqft_estimated`, `building.year_built_source`, `bill.seasonal{winter,spring,summer,fall}`, `bill.covers` (heating + cooling only), `heating_cooling` (P1's full `estimate_hc` answer).
  - Errors: 422 `{detail:{code,message}}` with codes `missing_input`, `needs_address` (+`hint`), `not_found`, `not_a_home`, `bad_unit_sqft`; 503 `model_unavailable` / `lookup_unavailable`.
  - Fields with no source yet are null or empty: `session_id`, p10/p90, `co2_t`, score/grade/percentiles/`hidden_rent_usd_mo`, `badges`, `questions` (filled by P2-03 and P2-04).
- **additive**, P2 (merge wave 2, dev `fd8c31c`), acks: P1 [ ] P2 [x] P3 [ ] P4 [ ]
  - `POST /estimate` / `POST /answer` body: `session_id` (string), `questions: [{id, text, options: [{value, label}]}]` (ids `heating_fuel`, `window_panes`, `floor_level`, `cooling_code`), `co2_t {p10, p50, p90}` t/yr, `badges` (ids from `app/badges.py` BADGES), score/grade/`grade_span`/`locked`/percentiles/`hidden_rent_usd_mo` filled; additive `grade_band_usd {p10, p50, p90}`, `grade_span_method`, `bill.band_method`, `bill.monthly`, `bill.note` (only for "No AC"), `building.warnings`, `answers`, `model_params`, `used_fixes` (after /fixes).
  - New `POST /answer` `{session_id, question_id, answer}` (option value, label words or "skip") → same shape. Errors: 422 `bad_answer`, 404 `not_found`.
  - New `GET /session/{id}` → the session's latest body; 404 `not_found`.
  - `POST /calibrate`: §10 fields (`pct_vs_expected_for_weather` in **percent**, `streak_months`, `badges`, `estimate`) + additive `year`, `month`, `actual_gas_ccf`, `expected_gas_ccf`, `noise_floor` (percent; null outside Dec–Feb), `meaningful`, `extracted` (what was read), `note`. Errors: 404 `not_found`, 422 `missing_input` / `unreadable_bill` (photo) / `bad_bill` (typed), 503 `vision_unavailable` / `model_unavailable`.
  - `GET /fixes/{session_id}`: per fix additive `unpriced`, `grh_item`, `cost_note`, `sources`; `usd_saved_yr`, `co2_kg_saved`, `new_grade` are **null** when `unpriced: true` (the model can't price that fix here); `cost_usd`, `rebate_usd` are **null** when there's no cited figure. Top level additive `grh_points_now_note`, `grh_points_required` (70). Errors: 404 `not_found`, 503 `model_unavailable`.
  - New `GET /forecast/{session_id}` → `{session_id, days: [{date, low_f, high_f, heating_usd, cooling_usd}] (7), week: {heating_usd, cooling_usd, total_usd, normal_total_usd, vs_normal_pct}, alerts: [{type: cold_snap | heat_wave | costly_week, date, detail}], source, method}`. Errors: 404 `not_found`, 503 `model_unavailable` / `forecast_unavailable`.
  - `POST /compare` `{listings: [{url | address, unit_sqft?}, {…}]}` → `{a, b, winner, diff_usd_yr}` + additive `confident` (true when the two p10–p90 ranges don't overlap). Errors: 422 `missing_input` (not exactly two), 422 `estimate_failed` + `listing: "a" | "b"` + that estimate's `code`/`message`.
  - `GET /city` → GeoJSON FeatureCollection (`application/geo+json`, gzip when accepted, ~3.6 MB gzipped / 13.8 MB raw), one Feature per scored footprint (`id` = footprint OBJECTID), `properties: {score, grade, excess_usd_per_sqft, type}`. 503 `city_unavailable`.
  - New `GET /leaderboard?scope=city|neighborhood` → `{best: [{benchmark_id, name, score, grade, cost_per_sqft, building_count, predicted, source}] (≤ 10, public benchmarking buildings only), worst_blocks: [{geoid, area_type: block_group | census_tract, building_count (≥ 5), score, excess_usd_per_sqft, predicted}] (≤ 10)}`. 422 `bad_scope`.

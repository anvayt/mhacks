- **additive**, P2 (merge wave 5a, Phase 2 accounts + commitments, dev `ef325b6`), acks: P1 [ ] P2 [x] P3 [ ] P4 [ ]
  - Auth: **agent-only** = header `X-Agent-Key: <AGENT_API_KEY>` (401 `agent_only`); **user** endpoints take the agent key or `Authorization: Bearer <token>` from web login (401 `login_required` / `login_expired`, 403 `forbidden`). Phones are masked in responses (`•••-•••-0142`).
  - `POST /auth/phone {phone, photon_user_id?, session_id?}` (agent) → `{user_id, created, current_property_id}`; idempotent; a web `session_id` becomes the home if there's none. 422 `bad_phone`.
  - `POST /auth/web/start {phone}` → `{login_id, code, text_body: "login <code>", redirect_url (Photon redirect with the text pre-filled; sms: link when USE_MOCKS=1), assigned_number_masked, expires_at}` (10 min). 422 `bad_phone`, 429 `too_many_codes` (3/phone, 20/IP per 10 min) / `signups_full` (5 new numbers an hour), 503 `photon_unavailable`.
  - `POST /auth/web/confirm {code, phone}` (agent; on an inbound "login <code>", phone = sender handle) → `{login_id, user_id, created}`. 404 `bad_code`, 410 `code_expired`.
  - `GET /auth/web/{login_id}` → `{status: pending | verified | expired, user_id?, token?}`; the bearer `token` is returned once (30 days). 404 `not_found`.
  - `GET /me/{user_id}` → `{user_id, phone_masked, alias, leaderboard_opt_in, timezone, reminder_prefs {channel: imessage|calendar|none, cadence: daily|weekly|monthly|off, hour_local 8–21, paused}, current_property_id, properties[], current_estimate, pending_checkin}`. `PATCH /me/{user_id} {alias?, leaderboard_opt_in?, timezone?, reminder_prefs?, pending_checkin: null?}` → same. 404 `not_found`, 422 `bad_alias` / `alias_required` / `bad_timezone` / `bad_prefs` / `bad_hour`.
  - Property: `{id, user_id, building_id (= /city id = /map building.id), address, session_id, active, move_in_date, move_out_date, unit_sqft {value, source, kind}, heating_fuel {value, source, kind}}`. `POST /properties {user_id, address|url, unit_sqft?}` → `{property_id, building_id, estimate, active}` (archives the previous home, clears a pending check-in; /estimate's errors). `POST /properties/{id}/activate` → Property. `GET /properties/{id}/history` → `{property_id, snapshots, bills, impact, commitments}` (snapshots/bills/impact empty until NC-05 merges). 404 `not_found`.
  - `POST /checkins/trigger {user_id}` (agent) → `{message_hint: "still_at_address", property_id, address, created_at}`, also on `/me` as `pending_checkin`. 409 `no_property`.
  - `GET /commitments/suggested/{property_id}` → `{property_id, commitments: [{catalog_id, title, who_acts, grh_item, grh_points, cost_usd, rebate_usd, cost_note, sources, note? (thermostat: 64°F WHO floor), requests? (landlord_request), projected: {usd_saved_yr, co2_kg_saved_yr, score_delta, new_grade, label: "projected_if_completed"} | null, pending_model, co2_per_net_usd, method}]}`, ranked by CO₂ per net $. Catalog ids: `air_sealing`, `attic_insulation`, `wall_insulation`, `window_upgrade`, `thermostat_setback`, `landlord_request`, `heat_pump`. `pending_model: true` = placeholder: every number null.
  - `POST /commitments {user_id, property_id, catalog_id, target_date?}` → Commitment `{id, user_id, property_id, catalog_id, status: accepted, evidence: projected, target_date?, accepted_at, reminder_channel, title}` (idempotent while accepted). `PATCH /commitments/{id} {status: completed | dismissed}` (completed → `evidence: reported`, `completed_at`; never backwards: 409 `bad_transition`). `GET /commitments?user_id=|property_id=` → `{commitments}`.
  - `POST /projection {property_id, commitment_ids: [commitment ids or catalog ids]}` → `{id, projection_id, property_id, commitment_ids, current: {score, grade, percentile_city, bill_annual, co2_kg_yr}, projected: {same + label}, delta: {score, usd_saved_yr, co2_kg_saved_yr, label}, label, modeled, not_modeled, method: "model_rerun", model_version, created_at}`. Never changes the current estimate.
  - Commitment errors: 404 `property_not_found` / `not_found` / `commitment_not_found`, 409 `bad_transition`, 422 `unknown_action` / `unknown_commitment` / `missing_input`, 503 `model_unavailable`.

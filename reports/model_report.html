Can we predict when MISO's grid is cleanest?

Every hour, the model predicts how much CO₂ each kWh of MISO electricity will cost over the next 24 hours. It learned from 120 days of real grid data. We then tested it on the last 14 days, which it never saw (Sep 18 onward).

A real prediction made Friday Sep 25 at 6 PM. Blue is what the model expected; gray is what actually happened. The star is the hour it would tell you to run the dryer.

3. Does it actually help?

We replayed the test period. Every hour, someone asks "when should I run my dryer in the next 24 hours?" Following the model's pick uses electricity that's 7% cleaner than running it right away.

Bottom line

  • Running at the model's pick saves about 7% CO₂ compared with running right away.
  • Just copying the last known day gets almost the same result, so the model is only slightly better than that shortcut so far.
  • What's holding it back: the grid data it sees is about a day old, and it has no wind forecast, even though wind is the biggest driver of MISO's clean hours.
